# Facebook Event Images - Manual Download Instructions

## Steps to Download Real Event Images from Facebook

### 1. Graeme Duffin Event (May 23, 2025)
- Go to: https://www.facebook.com/events/505353872514098
- Right-click on the colorful concert collage cover image
- "Save image as..." → Save to `public/images/events/graeme-duffin.jpg`

### 2. Sing for Serve Event (December 11, 2024)
- Go to: https://www.facebook.com/events/1118818683095354
- Right-click on the blue SERVE branded cover image
- "Save image as..." → Save to `public/images/events/sing-for-serve.jpg`

### 3. Happy to Serve Launch Event (October 4, 2024)
- Go to: https://www.facebook.com/events/488541410754988
- Right-click on the dark blue presentation/logo cover image
- "Save image as..." → Save to `public/images/events/happy-to-serve.jpg`

### 4. Family Fun Day Event (August 10, 2024)
- Go to: https://www.facebook.com/events/1456713141656694
- Right-click on the colorful teddy bears/picnic cover image
- "Save image as..." → Save to `public/images/events/family-fun-day.jpg`

## After Downloading

Once all 4 images are saved in `public/images/events/`, the website code will automatically use them instead of the Unsplash stock images.

The website will look for these exact filenames:
- `graeme-duffin.jpg`
- `sing-for-serve.jpg`
- `happy-to-serve.jpg`
- `family-fun-day.jpg`
